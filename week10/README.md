# Week 10 — Design Patterns

Пять задач на Java из лабораторной работы. В каждой задаче используются два
паттерна. Сторонних библиотек нет.

## Запуск

Открой папку week10 в VS Code. С расширением Java можно нажать Run над main
в любом Task1Runner–Task5Runner. Или запусти из терминала PowerShell:

```powershell
./run.ps1       # все задачи
./run.ps1 2     # только вторая задача
./run.ps1 test  # тесты
```

Для скрипта нужен JDK 9 или новее. Код компилируется для Java 8.

## Задачи

- task1: Strategy выбирает JSON или CSV, Decorator добавляет Base64 и метаданные.
- task2: Adapter разбирает ответ старого сервиса, Proxy хранит цену в кэше до истечения TTL.
- task3: Bridge отделяет тип уведомления от Email/SMS, Strategy решает, когда его отправлять.
- task4: Adapter переводит GBP в USD, декораторы добавляют упаковку, доставку и пошлину.
- task5: Bridge позволяет использовать S3 или NFS для видео и аудио, Proxy проверяет роль.

Исходники лежат в src, тесты — в test/LabTests.java. Проверочные Runner взяты
из задания без изменения тела. Результаты запуска записаны в verification.txt.

## Замечания

В PDF некоторые примеры расходятся с кодом. Здесь сохранены интерфейсы и порядок
вызовов из Runner.

В первой задаче сначала кодируются данные, затем добавляются метаданные:
так работает заданный порядок декораторов. Поэтому вывод отличается от образца
в PDF. Base64 только кодирует текст; надпись SHA-256 OK оставлена из примера,
настоящий хэш не вычисляется.

Во второй задаче TTL считается после получения цены. Возраст кэша в выводе
может отличаться при каждом запуске. Статус запрашивается напрямую;
отдельного ограничения частоты запросов в примере нет.

В четвёртой задаче используется BigDecimal, чтобы округлить $157.325 до $157.33.

В пятой задаче доступ разрешён ролям ADMIN, MEMBER и ENGINEER. В PDF встречаются
оба названия обычной роли. GUEST и неизвестные роли блокируются.

Запись файлов, отправка сообщений и загрузка из хранилищ здесь имитируются
выводом в консоль, как в задании.
